## 1. 한 문장 문제 정의 (Problem Definition)

> **[누가]** 강원대학교(춘천·삼척·강릉·원주) 재학생, 외국인 유학생, 교직원 및 지역주민이  
> **[언제]** 매주 장학금·학사일정·대외활동 공지를 찾고 신청을 준비할 때,  
> **[무엇 때문에]** 통합 홈페이지(`kangwon.ac.kr/ko`)의 캠퍼스별 공지 혼재와 `.hwp`/`.hwpx` 첨부파일 속에 숨겨진 자격요건(GPA·소득분위·재학생 지원불가 등), 그리고 행정실 문의 메일/지원서 작성 부담 때문에  
> **[얼마나 큰 비용을]** **매주 50분 이상의 탐색·열람 시간 비용, 무관한 공지를 읽는 에너지 비용, 수백만 원의 장학금을 놓치거나 한국어 경어 메일 작성에 망설이는 금전·불안의 '숨은 비용(Hidden Cost)'**을 지불하고 있습니다.

### 왜 기존 서비스(학교 홈페이지 검색 / 에브리타임)로는 부족한가?
- 학교 홈페이지 검색은 단순 **‘제목 키워드’**만 찾을 뿐, **본문이 비어있고 `.hwp / .hwpx` 첨부파일에 들어있는 모집요강을 열어보지 않고 내 학점·소득구간·캠퍼스 조건과 대조해주지 못하며**, 캘린더 등록(`.ics`)·담당자 정중 문의메일·지원서 초안 작성까지 **대신 끝내주지 못합니다.**

## 2. 핵심 기능 (Key Features)

1. **강원대학교 공식 게시판 실시간 연동 (`kangwon.ac.kr/ko/bbs/...`)**
   - 장학(`721`), 학사(`720`), 공모(`719`), 일반(`504`), 행사(`715`) 게시판의 실제 공지사항, 담당 부서 연락처/이메일, 첨부파일 다운로드 링크를 연동합니다.
2. **한글 오피스 없이 `.hwp / .hwpx` 첨부파일 자동 텍스트 추출**
   - 홈페이지 본문이 0자(빈 페이지)이고 `.hwp` 또는 `.hwpx` 첨부파일로만 제공되는 공고의 내부 텍스트를 자동 추출하여 웹 브라우저에서 즉시 열람하고 자격을 판정합니다.
3. **내 학적 조건(캠퍼스·신분·GPA·소득구간) 1초 적합도 판정**
   - 공고를 일일이 클릭하기 전에 리스트에서 `지원 가능` / `조건 확인(소득 0~4구간 등)` / `대상 아님(타 캠퍼스 전용, 졸업생 전용 등)`을 즉시 분류합니다.
4. **한국어 · 중국어 · 영어(KO / ZH / EN) 1클릭 전환**
   - 외국인 유학생과 다국어 사용자를 위해 공지 요약, 자격 판정 사유, UI 전체의 한·중·영 전환을 지원합니다.
5. **일을 끝까지 해내는 3대 AI 에이전트 액션 (Groq LPU 연동)**
   - 📅 **마감일 캘린더 자동 등록 (`.ics`)**: 마감 24시간 전 알림이 포함된 표준 캘린더 파일 생성
   - ✉️ **담당 부서 정중 문의메일 자동 작성**: 실제 공고 담당자 이메일(`khh8997@kangwon.ac.kr`, `jyh0908@kangwon.ac.kr` 등)로 즉시 발송 가능한 대학 행정 예절 경어 이메일 생성
   - 📝 **맞춤형 신청서·계획서 초안 AI 작성**: 공고문 및 `.hwp` 모집요강에 맞춘 500자 지원서 초안 생성

## 3. 설치 및 실행 방법 (Quick Start)

```bash
# 1. 필수 패키지 설치
pip install -r requirements.txt

# 2. 환경변수 설정 (.env)
cp .env.example .env
# .env 파일 내에 GROQ_API_KEY 입력 (웹 UI 우측 상단 'Groq API' 버튼에서도 직접 입력 가능)

# 3. 서버 실행
python app.py
```

실행 후 브라우저에서 **`http://127.0.0.1:8000`** 으로 접속합니다.
